# Linux — Hidden in Plain Sight

**Category:** Linux
**Difficulty:** Easy
**Points:** 50

## Description

Not everything on a Linux system wants to be found. We recovered a folder
from an old club machine — the previous owner swore they deleted everything
sensitive, but people are rarely as thorough as they think.

Download the archive, extract it, and find the flag.

## Hints

1. A plain `ls` only tells you part of the story. (Cost: 5 pts)
2. Configuration and cache directories are a classic place for forgotten
   secrets. Dig deeper than the surface. (Cost: 10 pts)
